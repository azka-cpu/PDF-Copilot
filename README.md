**Multi-PDF Library** — Upload and switch between multiple documents from the sidebar. - **User Accounts** — Supabase Auth with Row Level Security (RLS), ensuring users can only access their own PDFs. - **Persistent Chat History** — Conversations are saved per document and automatically restored when you reopen it. - **Page Citations** — Answers include the PDF page(s) used to generate the response. - **PDF Preview** — View the original PDF alongside the chat. -  **Scanned PDF Support** — Pages without extractable text automatically fall back to OCR using Groq's vision model. -  **Whole-Document Summaries** — Generate one-click summaries that are cached after the first generation. - **Web Search Fallback** — If the answer cannot be found in the PDF, the app can offer to search the web using Serper.dev / Google. - **Voice Input** — Ask questions using the browser's built-in speech recognition. - **Delete Individual Messages** — Remove a single question or answer from chat history. - **Streaming Answers** — Responses are displayed token-by-token. -  **Background PDF Processing** — Uploads return immediately while extraction, OCR, and embedding happen in the background. - **Daily Usage Limits** — Configurable per-user upload and question quotas. -  **Multi-Document Chat** — Select multiple PDFs and ask questions across all selected documents. ##  Tech Stack | Layer | Technology | |---|---| | Frontend | Next.js + Tailwind CSS | | Backend | FastAPI | | Authentication | Supabase Auth | | Database | Supabase Postgres | | Vector Search | pgvector | | Embeddings | Jina AI (`jina-embeddings-v3`) | | Chat & Summaries | Groq / Llama | | Vision OCR | Groq Vision Model | | Web Search | Serper.dev | | PDF Extraction | PyMuPDF | | Voice Input | Browser Web Speech API | ##  How It Works 1. The user signs in using **Supabase Auth** and uploads a PDF. 2. **FastAPI** extracts text page-by-page using **PyMuPDF**. 3. Pages without extractable text are automatically processed with **Groq's vision model** for OCR. 4. Each page is chunked and embedded using **Jina AI** (`jina-embeddings-v3`, 1024 dimensions). 5. Chunks are stored in **Supabase Postgres with pgvector**, along with their page numbers. 6. When a user asks a question: - The question is embedded. - A cosine-similarity search finds the most relevant chunks. - Results are scoped to the selected document(s) and authenticated user. 7. **Groq** generates an answer using the retrieved document context. 8. If the answer cannot be found in the PDF, the application can offer a **Serper.dev web-search fallback**. 9. Messages are saved to the database so chat history persists across sessions. ## Architecture ```text ┌──────────────────┐ │ Next.js │ │ Frontend │ └────────┬─────────┘ │ ▼ ┌──────────────────┐ │ FastAPI │ │ Backend │ └────────┬─────────┘ │ ┌────────────────┼────────────────┐ │ │ │ ▼ ▼ ▼ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ Supabase │ │ Jina AI │ │ Groq │ │ Auth + DB│ │ Embeddings│ │ Llama/OCR│ └──────────┘ └──────────┘ └──────────┘ │ ▼ ┌──────────┐ │pgvector │ │ Retrieval│ └────┬─────┘ │ ▼ ┌────────────┐ │ Serper.dev │ │ Web Search │ └────────────┘ ``` ## 🚀 Setup ### 1. Supabase Create a Supabase project and run: ```text supabase/schema.sql ``` If the project was already set up previously, re-run `schema.sql`. It adds the required `status` column to `documents`, the `usage_daily` table, and the `match_chunks_multi` and `increment_usage` RPC functions. Enable **Email Authentication** under: ```text Authentication → Providers → Email ``` For easier local testing, you can disable **Confirm email**. You will need: - Project URL - Publishable / anonymous key for the frontend - Secret / service role key for the backend > Never expose the backend secret/service role key in the browser. ### 2. Start the development server: ```bash npm run dev ``` Frontend: ```text http://localhost:3000 ``` ##  Deployment ### Backend Deploy the FastAPI backend to a platform such as **Railway** or another service with persistent compute. Update: ```env FRONTEND_URL ``` with your deployed frontend URL. ### Frontend Deploy the Next.js frontend to **Vercel** or a similar platform. Configure: ```env NEXT_PUBLIC_API_URL ``` along with the required Supabase environment variables. >  `.env` and `.env.local` values are only read when the process starts. Currently: - Chrome - Edge -  Firefox If the browser does not support the Web Speech API, the microphone button will not appear. ## Troubleshooting ### Supabase: `Invalid URL` Make sure `SUPABASE_URL` contains the Supabase project URL, not a PostgreSQL connection string. Correct: ```env SUPABASE_URL=https://your-project-ref.supabase.co ``` The `postgresql://...` connection string is intended for direct PostgreSQL clients such as `psql` or SQLAlchemy. ### Supabase: `Invalid API key` Make sure the backend is using the **secret/service key**, not the frontend publishable/anonymous key. The backend secret key must never be exposed to the browser. If you are using an older `supabase-py` version and the newer `sb_secret_...` / `sb_publishable_...` format is not supported, upgrade the package: ```bash pip install --upgrade supabase ``` ### Changes to `.env` Are Not Taking Effect Environment variables are loaded when the process starts. Stop the server completely: ```text Ctrl+C ``` Then restart it: ```bash uvicorn app.main:app --reload ``` Do not rely only on hot reload after changing `.env`. ### CORS Error If you see: ```text No 'Access-Control-Allow-Origin' header ``` check that `FRONTEND_URL` exactly matches the frontend origin. For local development: ```env FRONTEND_URL=http://localhost:3000 ``` Remember that: ```text localhost ``` and: ```text 127.0.0.1 ``` are different origins. Restart the backend after making changes. ### Model Not Found Provider model names are not standardized. If you receive a `model_not_found` error, verify the exact model ID in the provider's model catalog instead of relying on the model's display name. ### Payment Required / Model Not Available A `402 payment_required` error may mean that the selected model is not included in your account's free tier. Check your provider's billing and usage dashboard to confirm which models are available for your account. ### Email Sign-Up Rate Limit Supabase's free tier may have a low limit for confirmation emails. For local development, disable email confirmation under: ```text Supabase Dashboard → Authentication → Providers → Email → Confirm email: OFF ``` Users can then sign up and log in without waiting for a confirmation email. ### VS Code Import Errors If VS Code displays errors such as: ```text Import could not be resolved ``` make sure VS Code is using the Python interpreter inside your project's virtual environment. Open the Command Palette: ```text Ctrl+Shift+P ``` Then select: ```text Python: Select Interpreter ``` Choose the interpreter inside your project's `venv`. You can also verify dependencies with: ```bash pip install -r requirements.txt ``` ### Frontend Styles Not Updating If changes to the Next.js UI are not reflected, clear the `.next` cache: ```bash rm -rf .next npm run dev ``` On Windows, remove the `.next` directory manually if necessary. You generally do not need to run `npm install` again unless `package.json` changed or `node_modules` is corrupted.
